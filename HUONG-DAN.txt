Cách thay website cũ:
1. Sao lưu thư mục hiện tại.
2. Giữ thư mục .git nếu đang kết nối GitHub.
3. Chép toàn bộ file trong gói này vào thư mục banhangrong.
4. Nếu có file cũ trùng tên, thay thế bằng file mới.
5. Kiểm tra index.html bằng trình duyệt.
6. Terminal:
   git add .
   git commit -m "Lam moi website Anh Duong Materials"
   git push
